# السيرة الذاتية الشخصية — عبد الرحمن باوزير

موقع سيرة ذاتية عربي متجاوب يعمل مباشرة دون أدوات بناء.

## النشر على Cloudflare Pages
- ارفع `index.html` و`style.css` و`script.js` إلى جذر المستودع.
- Framework preset: None
- Build command: فارغ
- Output directory: `.`

لا يتضمن الموقع رقم الجوال أو البريد الإلكتروني أو رقم الهوية أو الحالة الاجتماعية أو الخبرات السابقة.
